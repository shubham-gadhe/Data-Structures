## Singly Linear Linked List (C)

## Features

- Display
- Count
- Insert First
- Insert Last
- Insert At Position
- Delete First
- Delete Last
- Delete At Position

## Time Complexity

|   Operation   | Complexity |
|---------------|------------|
| Insert First  |    O(1)    |
| Insert Last   |    O(n)    |
| Delete First  |    O(1)    |
| Delete Last   |    O(n)    |
